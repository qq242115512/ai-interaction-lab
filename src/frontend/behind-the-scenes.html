DevOps · 4 条教训

Docker 挂载了不存在的 index.html，看似成功

改 Docker volume 后必须 curl localhost 验证内容，不能只看 docker ps

阿里云 git pull 卡死（国内无代理）

GitHub Actions 云端 Runner 连中国 22 端口被墙，唯一通路是自托管 Runner

systemd 环境变量隔离导致重启后 API key 丢失

systemd service 文件用 EnvironmentFile，改完后 daemon-reload + restart 双确认

WSL2 IP 重启后变化，Docker daemon 代理失效

Docker daemon 代理配置写宿主机 IP，重启后拉镜像失败先检查 IP 是否变了

Orchestrator · 3 条教训

子 Agent 收到不合格上游产出后静默修补

下游反馈协议——用 3 点式拒绝：缺什么 → 为什么阻塞 → 要什么

两 Agent 同时改同一文件的不同区域被误判冲突

文件锁粒度细化到行级别区域——不同区域可并行，同区域需排队

同一角色被多次调用时，第二实例覆盖第一实例的输出

Agent Handoff Diff Check——后续任务卡片必须标注已有样式/属性锁定

Frontend · 2 条 & Backend · 1 条 & Security · 2 条

[Frontend]

CSS 动画和 GSAP 混用同一组元素导致页面抖动

所有动效统一在 GSAP 管理，CSS 只做 hover/transition

[Frontend]

移动端 hamburger 菜单点击无反应

所有 DOM 事件绑定必须放在 DOMContentLoaded 内或使用事件委托

[Backend]

Nginx proxy_buffering on 导致 SSE 被缓存

任何流式输出接口，Nginx 必须设 proxy_buffering off

[Security]

CORS allow_credentials=True + allow_origins=["*"] 被浏览器拒绝

当 allow_credentials=True 时，allow_origins 不能用通配符

[Security]

错误消息中包含 API endpoint 路径，泄露内部架构

生产错误消息必须脱敏——不含路径、不含 IP、不含内部服务名

// Feedback Protocol

子 Agent 收到不合格上游产出时的标准拒绝方式

1

缺什么

明确指出上游输出中缺少的具体信息或格式不满足的地方

2

为什么阻塞

解释缺少这个信息为什么导致自己无法继续执行

3

要什么

明确给出期望的格式/字段/标准，让上游知道怎么改

"静默修补是质量衰减的源头" —— 子 Agent 发现上游问题却不反馈，就像施工队发现设计图有错但不告诉设计师。第一次还行，第十次房子就塌了。
