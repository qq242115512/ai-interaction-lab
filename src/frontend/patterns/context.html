Pattern 05

多轮上下文

AI 记得之前聊了什么，持续追问不丢失线索

Design Rationale

解决的问题：很多 AI 对话是"金鱼记忆"——每句话都像第一句话。用户说"之前说的那个按钮"，AI 问"什么按钮？"。这种体验让人不想再用第二次。这违反了识别而非回忆（尼尔森第六原则）——系统应该替用户记住上下文，而不是让用户反复重复。

设计决策：后端维护 Session（会话），存储完整对话历史 + 评审摘要。每次新消息时把裁剪后的上下文（评审摘要 + 最近 6 轮对话）一起发给 AI。同时用上下文窗口管理在 token 限制内保留最重要的信息——超出限制时自动压缩旧对话为摘要。

生活类比：好的设计师跟你聊了 20 分钟后，不会问"对了，您家是几口人来着？"——因为他一开始就记住了。AI 也一样，上下文管理让 AI 变成一个"认真听你说话的人"，而不是"每次都要你重新自我介绍的陌生人"。

How It Works
1

评审时创建 Session

每次评审创建独立的 session_id，存储综合评分、各维度得分、视觉分析摘要。Session 有 1 小时 TTL，到期自动清理 — SQLite + WAL 模式保证服务重启不丢失。

2

chat_history 累积对话

每次追问追加到 chat_history，保留最近 12 条消息（6 轮对话）。超过限制时用 compact context 压缩为摘要，避免上下文窗口溢出。

3

构建 compact context 发送给 AI

每次 send 时打包：评审摘要（评分 + 维度）+ 最近对话历史 → 构建完整 prompt → 发送给 DeepSeek。AI 始终"记得"该 session 的全部关键信息。

src/backend/services/session_store.py
import sqlite3, time, json, uuid

class SessionStore:
    def __init__(self, db_path="sessions.db"):
        self.conn = sqlite3.connect(db_path, check_same_thread=False)
        self.conn.execute("PRAGMA journal_mode=WAL")
        self.conn.execute("""CREATE TABLE IF NOT EXISTS sessions (
            id TEXT PRIMARY KEY,
            data TEXT NOT NULL,
            created_at REAL NOT NULL
        )""")

    def create(self, data: dict) -> str:
        sid = str(uuid.uuid4())[:8]
        data["created_at"] = time.time()
        self.conn.execute(
            "INSERT INTO sessions VALUES (?, ?, ?)",
            (sid, json.dumps(data), time.time())
        )
        self.conn.commit()
        return sid

    def get(self, sid: str) -> dict | None:
        row = self.conn.execute(
            "SELECT data FROM sessions WHERE id = ?", (sid,)
        ).fetchone()
        if not row: return None
        data = json.loads(row[0])
        # 1-hour TTL
        if time.time() - data["created_at"] > 3600:
            self.delete(sid)
            return None
        return data

    def update(self, sid: str, data: dict):
        self.conn.execute(
            "UPDATE sessions SET data = ? WHERE id = ?",
            (json.dumps(data), sid)
        )
        self.conn.commit()
