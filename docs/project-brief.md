## 项目背景

### 为什么做这个项目
简历需要项目 → 找暑假实习 → 积累实习经历 → 毕业找好工作

### 项目选择过程
1. 之前聊过「AI 交互模式实验室」，但没有深入
2. 搜索南京市场，发现三个方向：AI 产品助理、AI 交互设计师、AI 应用落地
3. 排除 AI 产品助理（竞争太激烈，竞争指数 68）
4. 确定做「AI 设计评审工具」——面向设计学生，帮他们学习设计思维
5. 产品方向：不是工具类（给专业设计师），而是学习辅助类（给学生）

### 关键决策
- 不做纯展示平台，做具体可用的 AI 工具
- 目标用户选学生而非专业人士——AI 评审不完美也可接受，核心是启发思考
- 加一个「制作幕后」页面，展示 AI 工具链能力——这是真正的竞争力
- 服务器一年到期后可用 GitHub Pages/Vercel 免费替代
